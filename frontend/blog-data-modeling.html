E-Commerce dbt Data Modeling — Project Walkthrough

📅 March 2025 ⏱️ 12 min read

Overview

A data transformation project using dbt (data build tool) to process e-commerce sales data using the Medallion Architecture pattern. Built on PostgreSQL, fully containerized with Docker Compose, and automated with GitHub Actions CI/CD.

📦

Data Volume: 1,000 e-commerce transactions  |  dbt Version: 1.11.6  |  Database: PostgreSQL  |  Python: 3.11

Data Models — Layer by Layer

1️⃣ Bronze Layer — Raw Data Views

Model Type Role
br_ecommerce_sales View Raw pass-through of the seed data. Acts as a stable reference point — ensures downstream models always read from a named model rather than directly from the seed table.
💡

Views are used here because the raw data is small and doesn't require materialization. This keeps the Bronze layer lightweight.

2️⃣ Silver Layer — Cleaned & Validated

Model Type Role
sl_ecommerce_sales Table Cleaned, deduplicated transactions. Applies data quality checks — removes nulls, validates formats, and ensures each transaction is unique. Materialized as a table for query performance.

3️⃣ Gold Layer — Analytics-Ready

Model Type Purpose
fct_order Table Fact table containing transaction-level details — order ID, customer, product, quantity, price, and total amount. The central table for analytics queries.
dim_customer Table Customer dimension — deduplicated customer records with attributes for segmentation and analysis.
dim_product Table Product dimension — unique product catalog with categories, pricing, and product attributes.
⭐ Star Schema — Gold Layer

🏆 fct_orderorder_id, customer_id, product_id, qty, total
←
📦 dim_productproduct_id, name, category, price

Quick Start Guide 🚀

Prerequisites

  • Docker & Docker Compose
  • Git

Setup & Run

1. Clone the repository

git clone https://github.com/iimgaurav/dbt_e-com.git
cd e-com

2. Start PostgreSQL service

docker compose up postgres -d

3. Create dev_schema (first time only)

docker compose exec postgres psql -U gau -d e_com -c "CREATE SCHEMA IF NOT EXISTS dev_schema;"

4. Load seed data

docker compose run --rm dbt seed

5. Run dbt models

docker compose run --rm dbt run

6. Run tests

docker compose run --rm dbt test

7. Generate documentation (optional)

docker compose run --rm dbt docs generate
docker compose run --rm dbt docs serve

Visit http://localhost:8000 to view the docs.

Testing & Data Quality 🧪

All tests are defined in the tests/ directory and validate data integrity across all layers:

docker compose run --rm dbt test
✅

dbt tests validate uniqueness, not-null constraints, referential integrity, and accepted values across Bronze, Silver, and Gold models.

Common Commands 📝

Command Purpose
dbt debug Test database connection
dbt parse Validate dbt syntax
dbt seed Load CSV data into database
dbt run Execute dbt models
dbt test Run data quality tests
dbt docs generate Generate documentation
dbt clean Remove dbt artifacts

CI/CD Pipeline 🔐

Automated CI/CD with GitHub Actions. On every push/PR the pipeline runs:

🔄 GitHub Actions — CI/CD Flow
✅ dbt parsevalidate syntax
→
🌱 dbt seedload data
→
🏗️ dbt runbuild models
→
🧪 dbt testquality checks
→
📚 dbt docsgenerate docs
  • ✅ Validates dbt syntax (dbt parse)
  • ✅ Loads seed data (dbt seed)
  • ✅ Builds models (dbt run)
  • ✅ Tests data quality (dbt test)
  • ✅ Generates documentation (dbt docs generate)
